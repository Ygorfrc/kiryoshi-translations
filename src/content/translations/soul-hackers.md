## Sobre esta tradução

Soul Hackers é o ponto de partida de Kiryoshi Translations. A proposta é aproximar o público brasileiro de uma história que não recebeu localização oficial em português.

O projeto envolve trabalhar os textos, compreender sua estrutura e verificar como eles se comportam dentro do jogo. Tradução textual e conclusão do patch são etapas diferentes: revisão, reinserção e testes também precisam ser acompanhados.

## Notas de desenvolvimento

O status inicial foi cadastrado a partir do escopo deste site. Percentuais, ferramentas específicas, região compatível e resultados de testes ainda não foram fornecidos. Nenhum desses dados é presumido aqui.

## Aplicação do patch

O patch ainda não está disponível. O tutorial específico de instalação será publicado junto de uma versão autorizada, com os requisitos e cuidados necessários.

Não utilize instruções genéricas de outros jogos como se fossem compatíveis. Guarde uma cópia de segurança dos seus próprios dados e confira a versão indicada quando a documentação estiver disponível.
