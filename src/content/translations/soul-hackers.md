## Sobre esta tradução

Soul Hackers é o ponto de partida de Kiryoshi Translations. A proposta é aproximar o público brasileiro de uma história que não recebeu localização oficial em português.

O projeto envolve trabalhar os textos, compreender sua estrutura e verificar como eles se comportam dentro do jogo. Tradução textual e conclusão do patch são etapas diferentes: revisão, reinserção e testes também precisam ser acompanhados.

## Notas de desenvolvimento

A v38 é uma **prévia parcial, sem acentos**, para a versão USA (Title ID `00040000000C5600`). Há textos pendentes, recursos ainda não mapeados e conferência visual a concluir. Ter uma versão para download não significa que a tradução inteira esteja concluída.

Os dois ZIPs entregam os mesmos 18 recursos modificados, com organização e instruções próprias para Azahar e Luma3DS. São pacotes LayeredFS, não patches diferenciais xdelta. O jogo original é necessário: os pacotes não executam o jogo sozinhos.
