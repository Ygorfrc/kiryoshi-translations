> **Exemplo editorial:** este guia exemplifica uma publicação em Markdown. As informações de andamento dependem de confirmação.

## O que cada status significa

- **Planejado:** um título de interesse, ainda sem confirmação de trabalho ativo.
- **Em desenvolvimento:** o projeto está na etapa de produção informada pelo responsável.
- **Em revisão:** os textos estão sendo revisados.
- **Em testes:** a tradução está sendo verificada dentro do jogo.
- **Disponível:** existe uma versão autorizada do patch para download.
- **Pausado:** o trabalho foi interrompido por enquanto.

## Quando um número não aparece

“Não informado” significa que não há um percentual confirmado. Não equivale a zero e não permite estimar uma data de lançamento.
